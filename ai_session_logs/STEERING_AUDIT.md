# Steering Audit — Easy Rent Bali AI Assistant

Audit ini mencatat koreksi yang dapat ditautkan pada pekerjaan dan test yang
tersimpan. Ini bukan klaim bahwa setiap risiko telah dihilangkan.

| Area                      | Gejala/temuan                                                                                               | Koreksi dan verifikasi                                                                                                                                                                                         | Status/risiko tersisa                                                                                                |
| ------------------------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Database path MCP         | Proses MCP child tidak selalu memakai path `DATABASE_URL` yang sama dengan backend.                         | MCP manager meneruskan URL SQLite yang di-resolve kepada child process; API/MCP integration test menggunakan database terisolasi.                                                                              | Lulus pada tes; gunakan persistent volume yang sama saat deployment.                                                 |
| OpenRouter health         | Status konfigurasi/reachability dapat terbaca sehat meski completion gagal.                                 | Health check dan error provider dimodelkan terpisah; laporan/API menjelaskan bahwa health bukan jaminan kuota.                                                                                                 | Completion terbaru masih ditolak HTTP 429; belum pulih.                                                              |
| Rate-limit response       | Error generik “AI atau MCP sementara tidak tersedia” menyamarkan alasan provider.                           | Backend memetakan HTTP 429 ke `OPENROUTER_RATE_LIMITED`; tambah regresi API. API suite terakhir tercatat 16/16.                                                                                                | Tidak ada retry otomatis atau model berbayar; live completion perlu dites lagi setelah limit reda.                   |
| Perutean dan izin booking | Tool write yang diusulkan LLM tidak boleh dianggap sebagai persetujuan pengguna.                            | Booking write ditahan sebagai pending action server-side; hanya `/api/chat/confirm` dengan `confirm`/`cancel` yang memprosesnya. Uji menolak konfirmasi tanpa action dan teks chat biasa.                      | Pending action process-local (TTL 10 menit); satu replika dan kehilangan state saat restart perlu diperhitungkan.    |
| Hasil kendaraan           | Hasil beberapa tool dapat memuat kendaraan berulang.                                                        | Extraction kendaraan dideduplikasi sebelum response mobile; dicatat dalam regression test API.                                                                                                                 | Tetap bergantung pada data sumber dan model untuk konteks bahasa.                                                    |
| Label sumber MCP          | Deskripsi dan payload MCP A selalu menyebut development sample, padahal production dapat query DB operator. | Tool descriptions dibuat generik; `dataSource` kini `"database"` pada production tanpa opt-in seed, dan `"development-sample-data"` pada mode development/seed. Test MCP A memeriksa label sesuai environment. | Label mengidentifikasi konfigurasi sumber/seed, bukan provenance atau validitas record.                              |
| Data QA booking           | Booking E2E pernah tercipta untuk menguji persistence.                                                      | Booking dibuat pada database terisolasi dan database QA dibersihkan; log menyatakan referensi sebagai historis, bukan data production.                                                                         | Jangan gunakan nomor booking uji sebagai bukti operasional.                                                          |
| Status fitur mobile       | UI awal pernah memiliki layar booking preview; itu bukan alur live setelah integrasi.                       | Dokumentasi final membedakan alur production chat/dialog dengan booking form/review/success preview yang tidak tersedia pada production UI.                                                                    | PRD meminta flow tersendiri; masih menjadi gap produk.                                                               |
| Chat vs TTS model         | Qwen3 TTS 1.7B diusulkan sebagai model yang ingin digunakan.                                                | Verifikasi katalog menunjukkan `text->speech`, bukan chat/tool calling. Model ditambahkan hanya sebagai audio output on-demand; model percakapan dan MCP tetap terpisah.                                       | Bahasa Indonesia tidak tercantum pada daftar dukungan resmi; live audio belum diuji dan biayanya berbayar.           |
| Biaya audio               | Endpoint speech mengenakan biaya per karakter dan backend belum memiliki autentikasi pengguna.              | Pemanggilan hanya lewat tombol, teks maksimum 2000 karakter, rate limit 6/menit/IP, dan replay menggunakan cache perangkat.                                                                                    | Rate limit bukan pengganti autentikasi/spend limit; jangan deploy endpoint publik sebelum kontrol tersebut tersedia. |
| Deployment                | SQLite tidak aman di filesystem ephemeral.                                                                  | Panduan mensyaratkan persistent volume `/data` dan satu replica.                                                                                                                                               | Tidak ada provider, volume cloud, URL publik, APK, atau QR yang benar-benar dibuat/diverifikasi.                     |

## Prinsip audit bukti

- Test lama tetap berlabel historis; tidak diperlakukan sebagai kondisi live saat
  ini.
- HTTP 402 dicoba dengan stub, bukan memakai kredit OpenRouter nyata.
- Health endpoint tidak disamakan dengan keberhasilan completion.
- Sampel lokal dan booking QA tidak disebut inventaris atau data pelanggan
  aktual.
- Lihat [TESTING_REPORT.md](../docs/TESTING_REPORT.md) dan
  [DEPLOYMENT_REPORT.md](../docs/DEPLOYMENT_REPORT.md) untuk bukti serta isu
  tersisa.
